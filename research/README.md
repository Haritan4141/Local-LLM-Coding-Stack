# Research Notes

モデル候補、ランタイム要件、互換性、ベンチマーク仮説を「事実」と「未確認の主張」に分けて記録します。

各ノートには次を含めます。

- 対象 repository と調査日
- 情報源と確認日
- upstream claim / user-provided observation / local measurement の区別
- 正確な model artifact、量子化、runtime version
- 確認済み事項、未確認事項、反証や制約
- 次の測定と採用判断への影響

Web や upstream ページを確認していない情報を、公開済み・対応済み・高速化済みと断定しません。ローカル実測は `benchmarks/results/` に置き、ここでは解釈と調査メモを管理します。
